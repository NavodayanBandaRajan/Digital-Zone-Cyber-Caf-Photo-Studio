# Digital-Zone-Cyber-Caf-Photo-Studio
Project-6


A modern and responsive single-page website for Digital Zone Cyber Café & Photo Studio. This project is designed to showcase cyber café and photo studio services in a professional and attractive way using only HTML, CSS, and JavaScript.


📖 Project Overview

Digital Zone Cyber Café & Photo Studio is a business website that presents all essential information about a cyber café, including services, pricing, gallery, contact details, and location.

The website includes smooth scrolling navigation, typing text animation, image lightbox gallery, contact form interaction, and scroll animations using the AOS (Animate On Scroll) library.

This project was created to practice frontend web development and to build a real-world website that can be 

hosted online using GitHub Pages.
